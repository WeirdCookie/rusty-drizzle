# rusty-drizzle

A basic 2D plain generator using rust

## requirements

- newest version of rust from https://rust-lang.org/tools/install/
- git from https://git-scm.com/install/
## How to use

```bash
git clone https://github.com/WeirdCookie/rusty-drizzle.git
cargo run

```
